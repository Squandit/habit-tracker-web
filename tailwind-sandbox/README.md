# Tailwind sandbox

Separate from the main app on purpose. Nothing in here affects index.html,
styles.css or app.js one folder up.

    npm install          # once
    npm run dev          # watches src/input.css and rebuilds dist/output.css

Then open index.html in a browser. Edit classes, save, refresh.

- `src/input.css` is what you write.
- `dist/output.css` is generated. Never edit it.
